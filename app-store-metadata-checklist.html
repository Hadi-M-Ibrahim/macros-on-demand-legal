App Store Metadata Checklist

Concise checklist for closing the public legal/support asset gap before submitting Macros On Demand.

Public URLs

  • Privacy Policy URL: https://hadi-m-ibrahim.github.io/macros-on-demand-legal/privacy.html
  • Support URL: https://hadi-m-ibrahim.github.io/macros-on-demand-legal/support.html
  • Terms URL: https://hadi-m-ibrahim.github.io/macros-on-demand-legal/terms.html
  • Apple Standard EULA URL: https://www.apple.com/legal/internet-services/itunes/dev/stdeula/
  • Landing/reference URL: https://hadi-m-ibrahim.github.io/macros-on-demand-legal/

GitHub Pages Setup

  • Use the public macros-on-demand-legal GitHub Pages site for App Store metadata URLs.
  • The private source repository cannot serve GitHub Pages on the current GitHub plan; do not use its Pages URLs for App Store metadata.
  • Open each public URL above in a private/incognito browser window and confirm HTTP 200 rendering before App Review.

App Store Connect Fields

  • App Privacy Policy URL: use the Privacy Policy URL above.
  • Version Support URL: use the Support URL above.
  • Marketing URL, if desired: use the landing/reference URL or Support URL.
  • Terms of Use / EULA for subscriptions: use the Terms URL above, which references Apple's Standard EULA, or use the Apple Standard EULA URL directly if App Review requests the standard EULA link in metadata.
  • Do not add a custom EULA in App Store Connect unless the app owner has reviewed and intentionally adopted one.

Runtime Config

  • EXPO_PUBLIC_PRIVACY_POLICY_URL should point to the Privacy Policy URL.
  • EXPO_PUBLIC_TERMS_URL should point to the Terms URL.
  • EXPO_PUBLIC_EULA_URL may remain Apple's Standard EULA URL unless a different reviewed EULA is adopted.

Premium Metadata

  • Confirm the monthly and yearly Premium products are auto-renewable subscriptions in the same subscription group.
  • Confirm the one-time Premium product is a non-consumable.
  • Confirm subscription localization, review screenshots, pricing, and any monthly free-trial metadata match what the app displays through RevenueCat.
  • Confirm the paywall links to Privacy, Terms, and Apple Standard EULA pages from the production build.
  • Confirm Restore Purchases works in sandbox/TestFlight before review.
  • Deploy the Supabase delete-account Edge Function and confirm signed-in account deletion removes the Auth user before submitting.

App Privacy Questionnaire Review Items

Final answers must match the shipped build and provider dashboards. Based on the current app behavior, review these categories carefully:

  • Contact Info, if Sign in with Apple provides email or name and account sync stores it.
  • Purchases, because App Store purchases and RevenueCat entitlement metadata are used for Premium access.
  • Location, because current location and city/ZIP search can be used for nearby restaurant ranking.
  • User Content or Other Data, if saved meal identifiers, preferences, catalog review notes, or similar synced data are treated that way in App Store Connect.
  • Identifiers or Usage Data, because analytics events may include a signed-in user identifier and event properties.
  • Diagnostics, only if Apple, Supabase, RevenueCat, or any future crash reporting setup collects diagnostic data for this build.

Submission Notes

  • State that nutrition values are informational and may vary by restaurant location, customization, and menu changes.
  • State that Sign in with Apple is optional and used for Supabase-backed account sync.
  • State that the app offers Premium in-app purchases. If review is submitted with a hard paywall, state that core access requires Premium.
  • State that Premium access is verified through RevenueCat and purchases are managed by Apple.
  • Keep screenshots and metadata consistent with the live paywall, trial eligibility, and prices returned by App Store metadata.

This checklist is operational guidance for submission readiness. It is not legal advice and should be reviewed if the app's data collection, pricing, account sync, analytics, or third-party services change.
